# 黒龍 SNS運用（Instagram / TikTok）

Instagram で出している動画を TikTok にも展開するための、運用ルールと管理台帳。

## 3つの原則

### 1. マスターは1本、書き出しも1本

**IGアプリから動画をダウンロードして TikTok に上げるのは絶対にやらない。**
保存した時点で `@ユーザー名` の透かしが焼き込まれ、TikTok側で「他社ウォーターマーク＝非オリジナル」と
判定されリーチが落ちる。逆方向も同じ。

必ず **編集元（Premiere）から書き出したファイル** を、両方に別々にアップロードする。
共通セーフエリアに収めて作れば、プラットフォーム別の書き出しは原則いらない。

### 2. 台帳は1つだけ

動画1本 = 1行。IG用の表と TikTok用の表を分けた瞬間に更新が止まって破綻する。
`docs/投稿管理表.csv` をスプレッドシートにインポートして、これだけを更新する。

### 3. 最初は内容を出し分けない

同じ動画を、キャプションだけ変えて両方に出す。
TikTok専用の作り込みや投稿タイミングの最適化は、**30本たまって数字が見えてから**判断する。
最初から作り分けると、続かないうえに何が効いたのか分からなくなる。

## ファイル

| ファイル | 用途 |
| --- | --- |
| `docs/運用ルール.md` | 書き出し設定・セーフエリア・音源・投稿順など、判断の根拠込みの詳細 |
| `docs/投稿前チェックリスト.md` | 毎回コピーして使う確認項目 |
| `docs/投稿管理表.csv` | 管理台帳のテンプレート。スプレッドシートにインポートして使う |

## 運用の流れ

```
撮影・編集（週1でバッチ）
  ↓
マスター書き出し（1080×1920 / 共通セーフエリア / BGM埋め込み済み）
  ↓
台帳に行を追加（ID・タイトル・尺・キャプション2種）
  ↓
Instagram に投稿 → 台帳にURL記入
  ↓
数時間後 TikTok に投稿 → 台帳にURL記入
  ↓
1週間後に再生数を台帳へ追記
```

## 最初の判断ポイント

30本 / 約3ヶ月を目安に、台帳の数字を見て決める。

- TikTok が伸びている → TikTok先行 or TikTok専用尺を検討
- TikTok が伸びない → 冒頭2秒のフックを疑う（内容ではなく入口の問題であることが多い）
- どちらも横ばい → 本数ではなく企画を見直す
