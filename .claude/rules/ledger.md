# 管理台帳を触るときのルール

台帳はスプレッドシートに取り込んで運用する。カラム構成が変わると、
取り込み済みのシートと列がずれて、過去の行が壊れる。

## 変えてはいけないもの

- **カラム名と並び順**。追加・削除・並べ替えをしない。
- 1行 = 動画1本。プラットフォームごとに行を分けない。
- ID は `KR-0001` 形式の連番。欠番を詰めない。

## 記入の型

| 列 | 入れるもの |
| --- | --- |
| `承認ステータス` | `未提出` / `提出済` / `承認済` / `要修正` のいずれか |
| 日付列 | `2026-08-01` 形式 |
| ハッシュタグ列 | `#タグ1 #タグ2 #タグ3` のように半角スペース区切り |
| 数値列 | 数字のみ。単位や カンマ を入れない |

## 承認ステータス

`承認済` に変えていいのは、クライアントからテキストで承認の返事を受け取ったときだけ。
こちらの判断で先に `承認済` にしない。`承認済` 以外は予約投入しない。

## 記入例の行

`KR-0001` の行は記入例。運用開始時に削除する前提なので、
ここを実データの雛形として増殖させない。
