# 投稿前チェック

`docs/投稿前チェックリスト.md` を人間が目視で追う代わりに、
機械的に判定できるところだけ先に潰すためのスキル。
判定できないもの（映像の中身）は、確認すべき項目として残す。

## 手順

### 1. 材料を集める

ユーザーの入力から次を拾う。足りないものは**まとめて1回だけ**聞く。
1項目ずつ往復しない。

- 動画ファイル名
- IG キャプション / IG ハッシュタグ
- TikTok キャプション / TikTok ハッシュタグ
- 投稿予定日
- 使用音源

### 2. 機械的に判定する

`docs/制作ルール.md` の数値を根拠に、次を判定して結果を出す。

| 項目 | 判定 |
| --- | --- |
| ファイル名 | `KR_0001_タイトル_master.mp4` の形式か |
| ID整合 | ファイル名の連番が `docs/投稿管理表.csv` の `ID`（`KR-0001`）と対応するか |
| IGタグ数 | 3〜5個か |
| TTタグ数 | 3個程度か |
| IGキャプション | 冒頭1行で結論が出ているか（「続きを読む」で切れる前） |
| TTキャプション | 1〜2行に収まっているか |
| 投稿順 | IG先行 → 同日中の数時間後に TikTok になっているか |
| 音源 | 記入があるか。空なら不合格 |

### 3. 目視項目を残す

次はファイルを見ないと判定できない。**チェック済みとして扱わず、確認事項として列挙する。**

- 1080 × 1920 / 9:16
- テロップが共通セーフエリア内（上220px / 下450px / 左右120px を避ける）
- 冒頭2秒でフックが成立しているか
- BGM を編集で埋め込んであるか（IGのミュージック機能に頼っていない）
- 他SNSのロゴ・ウォーターマーク・UIの映り込み
- **Premiere から直接書き出したか**（IGアプリからダウンロードしていない）

### 4. 台帳の行を出す

`docs/投稿管理表.csv` のヘッダー順どおりに、追記する1行を CSV 形式で出す。
カラムを増やしたり並べ替えたりしない。まだ埋まらない列は空にする。

`承認ステータス` は必ず `未提出` で出す。ここを勝手に `承認済` にしない。

### 5. 結果の出し方

- 通った項目は列挙しない。**引っかかった項目と目視確認項目だけ**を出す。
- 全部通ったら「機械判定は全部通過。残りは目視◯項目」とだけ言う。
- 最後に台帳の行を出す。

## やらないこと

- `承認ステータス` を `承認済` に書き換える。承認は人がクライアントから受け取るもの。
- 予約投入の指示。`承認済` 以外は予約に載せない（`CLAUDE.md` の前提4）。
- チェックリストの項目をこのスキル側で増やす。増やすなら
  `docs/投稿前チェックリスト.md` を直してから、ここを合わせる。
