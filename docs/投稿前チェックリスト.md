# 投稿前チェックリスト

1本ごとにコピーして使う。

## 書き出し前

- [ ] 1080 × 1920 / 9:16 になっている
- [ ] テロップが共通セーフエリア内（上220px / 下450px / 左右120px を避ける）
- [ ] 冒頭2秒でフックが成立している（何の動画か・なぜ見る価値があるかが分かる）
- [ ] BGM を編集で埋め込んである（IGのミュージック機能に頼っていない）
- [ ] BGM が商用利用可の音源である
- [ ] 他SNSのロゴ・ウォーターマーク・UIが映り込んでいない
- [ ] 音量が -14 LUFS 前後

## 書き出し

- [ ] **Premiere から直接書き出した**（IGアプリからダウンロードしていない）
- [ ] ファイル名が `KR_0001_タイトル_master.mp4` の形式で、台帳のIDと一致している

## 台帳

- [ ] `投稿管理表` に行を追加した
- [ ] Instagram用キャプション＋ハッシュタグを書いた（冒頭1行に結論 / タグ3〜5個）
- [ ] TikTok用キャプション＋ハッシュタグを書いた（1〜2行 / タグ3個程度）
- [ ] 使用音源を記入した

## 投稿

- [ ] Instagram に投稿した
- [ ] 台帳に IG のURLと投稿日を記入した
- [ ] （同日中・数時間後）TikTok に投稿した
- [ ] 台帳に TikTok のURLと投稿日を記入した

## 1週間後

- [ ] IG 再生数・保存数を台帳に記入
- [ ] TikTok 再生数・いいね数を台帳に記入
