# 投稿前チェックリスト

1本ごとにコピーして使う。

## 1. 制作（詳細は `制作ルール.md`）

- [ ] 1080 × 1920 / 9:16
- [ ] テロップが共通セーフエリア内（上220px / 下450px / 左右120px を避ける）
- [ ] 冒頭2秒でフックが成立している
- [ ] BGM を編集で埋め込んである（IGのミュージック機能に頼っていない）
- [ ] BGM が商用利用可の音源
- [ ] 他SNSのロゴ・ウォーターマーク・UIが映り込んでいない
- [ ] **Premiere から直接書き出した**（IGアプリからダウンロードしていない）
- [ ] ファイル名が `KR_0001_タイトル_master.mp4` の形式で、管理表のIDと一致

## 2. 台帳への記入

- [ ] 管理表に行を追加した
- [ ] Instagram用キャプション＋ハッシュタグ（冒頭1行に結論 / タグ3〜5個）
- [ ] TikTok用キャプション＋ハッシュタグ（1〜2行 / タグ3個程度）
- [ ] 使用音源を記入
- [ ] 投稿予定日を記入

## 3. クライアント承認 ← ここを飛ばさない

- [ ] **4点セット**で提出した（動画 / キャプション / ハッシュタグ / 投稿予定日）
- [ ] その月の分をまとめて提出した（1本ずつ回していない）
- [ ] 承認の返事をテキストで受け取り、スレッドに残した
- [ ] 管理表の `承認ステータス` を `承認済` に更新
- [ ] `承認日` を記入

> `承認済` になっていないものは予約投入しない。例外なし。

## 4. 予約投入

- [ ] Meta Business Suite に予約を入れた（29日先まで / キュー上限25件）
- [ ] TikTok Studio に予約を入れた（キュー上限が小さいので分割投入）
- [ ] **IG先行 → 同日中の数時間後に TikTok** の順序になっている
- [ ] 予約日時が管理表の投稿予定日と一致している

## 5. 投稿後

- [ ] 実際に公開されたことを確認した（予約が失敗していないか）
- [ ] 管理表に IG のURLと投稿日を記入
- [ ] 管理表に TikTok のURLと投稿日を記入

## 6. 1週間後

- [ ] IG 再生数・保存数を記入
- [ ] TikTok 再生数・いいね数を記入
