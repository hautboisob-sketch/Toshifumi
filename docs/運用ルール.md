# 運用ルール（Instagram / TikTok 併用）

判断の根拠込みで書いてある。迷ったらここに戻る。

---

## 1. なぜ「IGからDLして再投稿」がダメか

Instagram のリールをアプリから保存すると、`@ユーザー名` のウォーターマークが動画に焼き込まれる。

- **TikTok側**: 他社プラットフォームの透かしが入った動画は「非オリジナル」と判定され、おすすめへの露出が制限される
- **Instagram側**: 同じ内容の動画が複数ある場合、「最初に投稿されたオリジナル」だけをレコメンドに出す挙動がある

つまり **透かし入りの転載は、上げた側だけでなく元の側の評価も下げうる**。

### 正しい手順

```
Premiere のマスター
  ├→ 書き出し（透かしなし） → Instagram にアップロード
  └→ 同じファイル            → TikTok にアップロード
```

同じファイルを2回アップロードするだけ。ファイルは1つでいい。

### 自動転載ツールは当面使わない

Repurpose.io のような IG→TikTok 自動転送サービスは、透かし処理や非オリジナル判定の挙動が
サービス側の実装に依存する。手動アップロードが週数本なら手間は数分なので、
運用が軌道に乗るまでは手でやる。

---

## 2. 書き出し設定

| 項目 | 値 |
| --- | --- |
| 解像度 | 1080 × 1920（9:16） |
| フレームレート | 素材に合わせる（30 or 60fps） |
| コーデック | H.264 / MP4 |
| ビットレート | VBR 2パス、目標 10〜16 Mbps |
| 音声 | AAC 48kHz ステレオ 192kbps 以上 |
| ラウドネス | -14 LUFS 前後 |

両プラットフォームとも再エンコードが入るので、元を高ビットレートで出しておく。
アップロードするファイルの容量を節約する意味はない。

---

## 3. セーフエリア（テロップ位置）

TikTok と Instagram リールは UI の位置が違う。**両方で隠れない共通ゾーン**に収める。

1080 × 1920 を基準に、以下を避ける：

| 方向 | 避ける幅 |
| --- | --- |
| 上 | 約 220px |
| 下 | 約 450px |
| 左右 | 各 約 120px |

→ 実質の安全領域は **840 × 1250px**。

### 各プラットフォームの癖

- **TikTok**: 右側に「いいね・コメント・シェア」が縦に並び、下部にキャプションが乗る。下部が特に狭い
- **Instagram リール**: フィードに出るかリールタブに出るかで UI が変わる。いいねボタンが中央より下寄りで、比較的自由度は高い

Instagram単独なら下の余白はもっと使えるが、**TikTok に合わせて狭いほうに統一する**。
テロップの縦位置は「上寄せ〜中央」でルール化すると迷わない。

Premiere にセーフエリアのガイド用 PNG を1枚作って、全プロジェクトの最上位トラックに
非表示で置いておくのが早い。

---

## 4. 音源の扱い ← ここが一番ハマる

**Instagram アプリ内の「ミュージック」機能で付けた曲は、動画データに含まれない。**
プラットフォーム側で権利処理して再生時に合成しているだけなので、TikTok には持っていけない。
TikTok のトレンド音源も同様に IG へは持っていけない。

### 方針：BGMは編集段階で埋め込む

商用利用可の音源（Epidemic Sound / Artlist / 購入済み音源）を Premiere でミックスして書き出す。
1本のファイルが両方でそのまま成立する。

**トレードオフ**: トレンド音源に乗るという伸ばし方は捨てることになる。
ただし黒龍のような「内容で見せる」動画では、音源トレンドへの依存度は低い。
まずは埋め込みで統一し、必要になったら例外を作る。

台帳の `音源` 列に使った曲名を残しておくと、後で権利確認が必要になったとき助かる。

## 5. 尺の設計

| プラットフォーム | 傾向 |
| --- | --- |
| Instagram リール | 短めが有利。最後まで見られる率が効く |
| TikTok | 1分超でも回る。ただし冒頭の離脱が全て |

**両方に出す1本は 20〜45秒** が両立しやすい。

これを超える内容は、無理に1本に詰めず **前後編に割る** か、
**TikTok専用の長尺** として台帳に「TikTokのみ」と記録して分ける。

---

## 6. 投稿順とタイミング

Instagram は「最初に投稿されたオリジナルを優遇」する挙動があるため、
**TikTok先行 → IG後追い** は IG 側が不利になりうる。

### 推奨

```
Instagram に投稿
  ↓ 数時間後（同日中）
TikTok に投稿
```

完全同時ではなく数時間ずらすのは、どちらの流入で伸びたのかを切り分けやすくするため。
「IG先行・同日中にTikTok」を固定ルールにして、判断コストをゼロにする。

### 頻度

- 編集は **週1でまとめて**（バッチ）
- 投稿は **週2〜3本に分散**

まとめ編集・分散投稿にしないと、編集の日が来ないまま投稿も止まる。

---

## 7. キャプションとハッシュタグの出し分け

動画は同じ、テキストは変える。台帳に両方を持たせる。

### Instagram

- 冒頭1行に結論。「続きを読む」で切れる前に価値を出す
- 検索されうるキーワードを本文に自然に含める
- ハッシュタグは **3〜5個**。関連性の高いものだけ

### TikTok

- **1〜2行**。長文は読まれない
- ハッシュタグ **3個程度**
- 動画内テロップとキャプションの内容を重複させない

---

## 8. ファイル命名

```
KR_0001_タイトル_master.mp4
```

- `KR` = 黒龍
- `0001` = 通し番号（台帳の ID と一致させる）
- 共通1本で出せる前提なので、プラットフォーム別サフィックスは原則つけない
- 別出しが必要な回だけ `_TT` / `_IG` を付ける

台帳の ID とファイル名が一致していることが重要。
「どの動画の話をしているか」が一意に決まる状態を保つ。

---

## 9. 数字の見方

台帳に投稿1週間後の数字を入れる。追うのは4つだけ。

| 指標 | 見る理由 |
| --- | --- |
| 再生数 | 露出の総量 |
| IG保存数 | 「後で見返したい」＝内容の価値。IGではリーチに効く |
| TikTokいいね数 | 反応の強さ |
| 両者の再生数の比 | どちらのプラットフォームに寄せるかの判断材料 |

視聴維持率は取れるなら取る（両プラットフォームともアナリティクスで確認可能）が、
台帳の必須項目にはしない。**入力項目が多い台帳は続かない。**

---

## 10. やらないこと

- IGからダウンロードした動画を TikTok に上げる
- 自動転載ツールでの IG→TikTok 自動転送（軌道に乗るまで）
- プラットフォーム別に台帳を分ける
- 最初からTikTok専用コンテンツを作る
- 数字が出る前に運用ルールを変える（最低30本は同じルールで回す）

---

## 補足：黒龍が酒類ブランドの場合

TikTok は酒類の扱いが Instagram より厳しい（広告出稿は不可、オーガニック投稿も年齢制限や
コミュニティガイドラインの対象になりうる）。該当する場合は、アカウント開設前に
TikTok の最新のコミュニティガイドラインと年齢制限設定を確認すること。
このルール自体は変わらないが、**アカウント運用の可否そのものが前提として要確認**になる。
